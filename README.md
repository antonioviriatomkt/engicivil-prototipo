# Engicivil — protótipos de website

Website-conceito da [Viriato](https://viriato.com.pt) para a Engicivil (Aveiro). **Não é o site oficial da Engicivil.**
Dois protótipos (F e G) em desenvolvimento a partir das direções de design de 21/10/2026.

```bash
npm install
npm run dev      # http://localhost:5173 — índice com os protótipos e mockups
npm run build    # → dist/
```

Instruções de trabalho (pessoas e Claude): [`CLAUDE.md`](CLAUDE.md). Estado de cada protótipo: [`sessions/f/STATUS.md`](sessions/f/STATUS.md) · [`sessions/g/STATUS.md`](sessions/g/STATUS.md).

Imagens: site público engicivil.pt (propriedade da Engicivil), usadas só neste conceito.
